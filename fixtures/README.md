# Fixtures

本目录只用于**临时**真实样本。样本在完成验证后按用户要求删除，工作区不保证保留任何文件。

## 规则

- 代码和自动测试不得依赖 `fixtures/` 中的真实样本；测试必须使用内存构造的最小样本。
- 真实样本只用于手工回归、字段质量检查和边界验证。
- 使用样本时记录来源与预期结果到本轮说明或 `docs/05-implementation-history.md`；样本验证后删除。
- 不提交来源不明的大文件，不复制、不裁剪、不转码样本。
- 当前目录可能为空；历史验证结论以 `docs/05-implementation-history.md` 和
  `docs/08-format-notes.md` 为准。
