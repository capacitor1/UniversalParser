# Archive

本目录保存 Phase 6/7/8 期间形成的**历史快照**，用于追溯完整理由、验收细节和被压缩掉的
实现记录。它不参与当前规则判定；与主文档冲突时，以 `00` ~ `08` 为准。

| 文件 | 内容 |
|---|---|
| `01-issue-closeout-2026-11-17.md` | Phase 6 逐项结论、Phase 7 新增格式的入口记录、当时的验证清单 |
| `02-product-decisions-full.md` | D-001 ~ D-043 的完整决策文本：原因、实现含义、验收、历史背景 |
| `08-format-notes-full.md` | 各格式的完整笔记：规范摘录、已删除样本的来源/命令、实现文件列表、逐项测试名 |
| `release-1.0.0.md` | v1.0.0 发布记录：产物、构建命令、格式范围、已知限制、校验信息 |
| `release-1.0.1.md` | v1.0.1 本地发布记录：issue#1 维护、产物、构建、校验信息 |

归档原则：

- 只追加，不把归档内容重新当作当前规范。
- 主文档只保留当前生效规则、当前状态和仍需遵守的坑。
- 已经删除的旧代码、旧测试、临时样本不再恢复；归档只记录它们曾经存在及结论。
